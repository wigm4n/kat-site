# kat-site

Одностраничный сайт-визитка системного и бизнес-аналитика: обо мне, опыт работы, навыки, контакты,
кнопки «Скачать резюме (PDF)» и «Написать в Telegram». Бело-розовое оформление, адаптивная вёрстка.

Чистые HTML + CSS + немного JS, без сборки и зависимостей.

## Быстрый старт

1. Откройте `index.html` в браузере (или `python -m http.server 8080` и <http://localhost:8080>).
2. Замените заглушки (имя, тексты, контакты, фото, `assets/resume.pdf`) — они помечены `TODO`.
3. Опубликуйте сайт и подключите домен — по инструкции в [DEPLOY.md](DEPLOY.md).

## Структура

```text
index.html          страница
assets/css/         оформление (цвета — в :root в начале style.css)
assets/js/          мобильное меню, анимации
assets/img/         фото
assets/resume.pdf   резюме для скачивания (замените заглушку!)
robots.txt, sitemap.xml   для поисковиков
```
